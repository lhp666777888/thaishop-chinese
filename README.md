# ThaiShop 中文情景会话练习

## 项目简介

**ThaiShop 中文情景会话练习** 是一个面向泰国初级汉语学习者的网页互动练习项目。项目以“去商店买东西”为主题，把学生熟悉的购物流程转化为中文学习任务，帮助学生在具体情境中练习购物词汇、句子和角色对话。

本项目适合用于国际中文教育课堂，尤其适用于 HSK1—HSK2 入门阶段学生的情景会话练习。

## 适用对象

- 泰国初级汉语学习者
- 零基础或初级水平学生
- 适合 15—18 岁青少年课堂使用
- 适合购物、商品、价格、颜色、数量等主题教学

## 主要功能

1. **首页情景选择**  
   学生可以选择不同购物情景，例如买饮料、买衣服、买手机产品、买日用品。

2. **中文、拼音、泰文注释**  
   每个主要句子和词汇都配有中文、拼音和泰文解释，方便初级学生理解。

3. **角色会话练习**  
   学生可以分别扮演顾客和售货员，完成情景对话。

4. **A/B 对话流程**  
   对话按照 A、B 顺序展开，适合课堂中两人一组练习。

5. **本地音频播放**  
   网页中已接入中文句子的音频，点击播放按钮即可听音频并跟读。

6. **购物车模拟**  
   学生可以把商品加入购物车，练习“加入购物车”“结算”“优惠券”等购物表达。

7. **课堂操作引导**  
   页面包含简单的学习流程提示，帮助学生知道如何使用网页进行练习。

## 课堂建议流程

建议教师按照以下流程使用：

1. 教师先展示首页，让学生了解四个购物情景。
2. 学生选择一个情景进入练习。
3. 学生先听 A 句，再听 B 句。
4. 学生模仿录音进行跟读。
5. 两人一组进行角色扮演。
6. 练习一次后交换角色。
7. 最后进入购物车页面，完成综合购物表达练习。

其中：

- `audio/`：音频文件夹。
- `assets/`：图片资源文件夹。

## GitHub Pages 部署方法

### 第一步：上传文件

把以下文件上传到 GitHub 仓库：

```text
index.html
README.md
```

注意：网页主文件必须命名为：

```text
index.html
```

### 第二步：开启 GitHub Pages

进入仓库后：

1. 点击 **Settings**
2. 点击左侧 **Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选择 **main**
5. Folder 选择 **/root**
6. 点击 **Save**

等待 1—3 分钟后，GitHub Pages 会生成网站链接。

链接格式通常为：

```text
https://你的用户名.github.io/仓库名/
```

## Netlify 部署方法

也可以直接使用 Netlify 部署：

1. 打开 Netlify
2. 新建项目
3. 上传包含 `index.html` 的文件夹
4. 部署完成后复制网址
5. 将网址或二维码发给学生使用

## 使用注意事项

1. 本项目为教学模拟软件，不连接真实购物平台或真实支付系统。
2. 项目没有使用 Shopee、PromptPay 等真实平台的商标或官方页面。
3. 页面中的购物、结算、购物车均为课堂学习情境。
4. 如果在手机浏览器中没有声音，请检查媒体音量，并确认网页允许播放音频。
5. 建议教师在课堂使用前先测试网页链接、音频播放和投屏效果。

## 教学目标

通过本项目，学生能够：

- 识别常见购物商品名称
- 听懂并模仿基础购物句子
- 使用“我想买……”“多少钱？”“可以吗？”等句型
- 在顾客和售货员角色中进行简单对话
- 在模拟购物流程中完成中文交际任务
